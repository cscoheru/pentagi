# 趋势 — 从 22 条有效条目中读出的结构性变化

> **与 `../hot/hottest-topics.md` 的区别**：
> 「最热」= **哪几件事现在最热**（话题排序，瞬时状态）。
> 「趋势」= **哪些结构性变量在移动**（方向性判断，跨周期成立）。
>
> **证据纪律**：每条趋势标注 `证据强度` —— **强**（≥2 个独立来源，或有具体数字支撑）/
> **中**（1 个来源但有日期或数字）/ **弱**（1 个来源、无日期无数字，仅方向性暗示）。
> **弱证据的趋势不作为结论使用**，保留在此仅供下一轮验证。

---

## A. 市场面

### A1. 回调被挤掉的是泡沫，不是全部定价 —— 但**尚未出现反转确认**
**证据强度：强**

- 大益行情网：2 月以来"大部分茶跌幅比较大，**挤掉了不少泡沫**"，近期"找货的人明显多了"
- 找找茶行情表：两个价位带同步下跌且幅度有限（−¥580 / −¥2,030）
- 单日区间 26000 → 34500（**单日，不是序列**）

**移动的方向**：从"单边下跌"转向"低位换手"。**但"找货出现"是需求端信号，不是价格端确认。**

**证伪条件**：若后续 2 周的日度序列没有站上 34500，则"找货窗口"只是**反弹噪音**。
本次未取到连续序列，无法判定。

### A2. 原料端与成品端出现**分层错配**
**证据强度：中**

- 2026 春茶季：中小树"价格暴跌、订单萎缩、茶农焦虑"；古树"能否撑住"仍是问号
- 成品端：明星品种（精品孔雀、群峰、仓颉、轩辕号）出现找货需求
- 行业标准口径（艾媒 2025-04-14）：高端年份茶需陈化 **≥5 年**、零售 **≥2000 元/357g**

**移动的方向**：低端原料供给过剩与高端成品稀缺**同时存在**，价格压力集中在**中低端生茶**
（当年新茶、中小树、台地），而**陈年老茶与高端品牌货**反而抗跌。
**注意**：这条趋势的"中"评级正是因为它由**行业新闻（台湾茶壶网）+ 品牌行情（大陆）**两个
不同市场拼合而成，而非同一市场的连续数据。

### A3. 金融茶属性在主动稀释
**证据强度：中**

- 大益传奇1975：生熟茶均 **≤1000 元**
- 媒体定性为"高端茶叶集体转身"
- 对照：轩辕号 / 千羽孔雀 的数万至数十万价位

**移动的方向**：品牌方主动把产品线往**日常消费品价格带**拉。金融茶属性（囤货—炒作—复价）
与日常消费属性（复购—频次—口碑）在同一品牌内**分层并存**。

## B. 产品面

### B1. 规格分化：从"单饼定价"到"单件/多提"组合定价
**证据强度：中**

- 找找茶 2501 7542 出现 **5 千克规格**独立档案页
- 同一批次同时存在 **357 克/片 · 7 片/提 · 6 提/件** 的报价体系
- 同一站点给出 **¥2.23 万/件** 与 **¥29.00 万/件** 两个价位带
- 海外：大益官方商城主力规格为 **300g**（RM 78.00 / 1901 熟饼）

**移动的方向**：同一品牌同一批次，按**总量**分层报价（单饼 / 提 / 件 / 千克），
**大宗规格与投资规格的价差本身成为信息**。海外 300g 规格说明**区域规格表独立于国内**。

### B2. 品牌史被"重新讲"以支撑溢价
**证据强度：弱**（但三条来源共振，值得列为观察项）

- 7542："持续生产时间最长的生茶" + "品饮量最大的生茶" + **50 周年纪念版**
- 孔雀系列：2003 年四星孔雀 → **勐海茶厂 85 周年庆典**
- 第三代智能发酵技术：第一代自然发酵 → 第二代人工渥堆 → **第三代智能发酵**

**移动的方向**：当"年份 + 稀缺"讲不动时，改讲**连续性（50 年）、谱系（85 年）、技术代差（3 代）**。
三条线索的共同点是：**都不依赖具体年份**，因而**不受陈化年份争议影响**。

### B3. "包销"成为独立于厂家的第三方定价参与者
**证据强度：中**（单一来源但有具体主体与事件）

- 2401 批《源生古茶园珍品》**大2青饼**
- 包销方："**芳村大姐和二姐**"
- 事件定性："对行情的**搅动**"
- 关联："印象版纳拥抱大益新政策'**锁仓**'概念"

**移动的方向**：定价参与者从"厂家（配货政策）"扩展为
**厂家 → 芳村包销方 → 二级市场**三层。**锁仓政策 + 包销权**是同一套流通盘控制工具的两面。

## C. 渠道面

### C1. 行情信息已高度"中介化"，**源头稀缺**
**证据强度：强**（多个独立站点指向同一结构）

本次 22 条有效条目中，**提供具体数字的几乎全部来自中介/数据站，而非产地或协会**：

| 类型 | 站点 | 提供什么 |
|---|---|---|
| 行情数据站 | dayihangqing.com、zzctea.com | 日度/批次报价、涨跌 |
| 回收/经纪 | pinpaipuer.com（长期回收）、dayihangqing.com（上门回收） | 回收价、挂牌、测评 |
| 拍卖 | lhauction.com.hk | 历史成交记录 |
| 电商货架 | jd.com、1688.com、shopee.tw、taeteamall.com.my | 零售/批发标价 |
| 跨品牌索引 | puercn.com | 数十品牌行情入口 |
| 垂直媒体 | ipucha.com、19lou | 产品档案、选购攻略 |
| **行业研究** | iimedia.cn | **唯一一个非"茶圈"的机构来源** |
| **协会/产地官方** | — | **零条目** |

**移动的方向**：**信息供给严重偏向交易环节，缺失生产端与监管端**。
后果是：协会口径（产量、天气、标准）、产地收购价、监管政策**在本轮全部缺失**，
无法交叉验证中介行情的真实性。

### C2. "回收价"正在成为最诚实的行情代理指标
**证据强度：中**

- 知乎专栏（2026-04）：以"**芳村回收**"为口径记录大益回收价
- 券拍（2019-05-25）：80 年代 8582 六筒四十二片，**709 万港元**，每片均价 **168,809 元**
- dayihangqing.com：同时提供"上门回收服务"与"新老茶价值评估/真伪鉴别"
- pinpaipuer.com：设"**长期回收**"业务

**移动的方向**：挂牌价、零售价、回收价、拍卖成交价构成**四层价差**。
回收价是**唯一有真实成交背书**的一层，也是**情绪最冷**的一层 ——
本次检索中，**回收口径与挂牌口径给出的方向一致（都指向回调）**，这比单一挂牌价更可信。

### C3. 消费端内容以"导购"形态存在，不以"资讯"形态存在
**证据强度：弱**

- 19lou 两篇均为"必看/最新爆款"型**选购攻略**，非行业资讯
- Shopee / 京东 / 1688 均为**报价聚合页**，无固定资讯条目
- 唯一"资讯化"的终端内容是**媒体报道**（大洋网"亲民化"）

**移动的方向**：在茶圈外，消费端信息被电商与论坛的**商品化导购**占据。
这意味着**"舆论热度"在茶圈外基本不可观测** —— 与 `hot/` 提到的社交平台全零产出互为印证。

## D. 数据/基础设施面（关于本次检索本身）

### D1. 检索侧的最大单点缺陷是**"缺少日期"**，而非"缺少内容"
**证据强度：强**（29/29 统计可复算）

- Searxng 结果格式化**支持** `**Published:**` 字段（`backend/pkg/tools/searchers/searxng.go:173-175`）
- 本次 29 条中 `Published` 出现 **0 次**、`Author` **0 次**、`Source Engine` **29 次**
- 根因：`SEARXNG_CATEGORIES` 默认 `general`（general 类目不带 `publishedDate`；`news` 带）

**移动的方向**：**内容获取能力没问题，日期标注能力被配置卡住了。**
一个环境变量（`SEARXNG_CATEGORIES=news,general`）即可把 22 条里 10 条的
"日期未确认"变成真实日期。详见 `../analysis/blocked-causes.md` §3.5 / §4 L1。

### D2. 失败的主要来源是**Agent 行为**（猜测域名），不是工具能力
**证据强度：强**（12/12 逐条归因）

- 7/12（58%）失败源于 Agent 自行拼造域名（DNS 失败 / 404 / 域名停放 / 证书无效）
- 真实官网 `www.taetea.com.cn` **已在 Searxng 结果 #8 中检出**，Agent 却抓了猜错的 `dyfc.com.cn`
- 仅 4/12 属真正的工具边界（3 个 JS 反爬 + 1 个客户端空壳）

**移动的方向**：这是**可由提示词一次性修复**的缺陷，不是需要重构工具栈的缺陷。

## 本文件**没有**回答的问题（留给下一轮）

1. **没有连续时间序列** —— 全部是单点快照，无法做趋势斜率判断。
   需要：日度行情页的连续抓取（dayihangqing.com 的日度页、puercn.com 的日度表）。
2. **没有协会/产地/监管口径** —— 零条目，无法交叉验证中介行情。
   需要：定向检索中国茶叶流通协会、西双版纳州统计局、国家标准（GB/T 22111）。
3. **没有社交热度数据** —— 贴吧/微博/知乎/小红书全零，无法做真实热度排序。
   需要：`site:` 定向检索 + Firecrawl（`FIRECRAWL_API_KEY`）走 JS 渲染路径。
4. **没有非大益品牌的独立条目** —— 除 puercn.com 的索引入口外，只有零散提及。
   需要：按品牌分别检索（八角亭 / 陈升号 / 福今 / 澜沧古茶 / 勐库戎氏 / 中茶 / 下关）。
5. **2026 年 8–10 月行业新闻空窗约 3 个月** —— 根因见 D1（`time_range` 未设 + `categories=general`）。
